# TypeBot · 拟人打字机器人（Windows）

以接近人类的自然节奏，把一段文字“敲”进任意程序的文本框。速度（WPM）可调，带随机节奏、标点停顿、思考停顿和“打错再改正”。

纯 Python + tkinter，**无需安装任何第三方库**（需要 Python 3.10+）。

## 启动

双击 `TypeBot.bat`，或：

```bash
python typebot.py
```

## 使用

1. 在 TypeBot 左侧填入要输入的文本（或选择“按快捷键时的剪贴板内容”）。
2. 调好速度等参数。可先点 **速度预览** 感受一下。
3. 点击目标程序里的文本框（Word、浏览器、聊天框、编辑器……）。
4. 按 **Ctrl + Alt + \\** 开始。再按一次暂停，再按继续；打字中按 **Esc** 立即停止。

也可以点界面上的“开始”按钮，然后在 3 秒倒计时内点击目标文本框。

## 关于 Fn 键

Fn 键在绝大多数键盘上由键盘固件自己处理，按下时不会向 Windows 发送任何信号，因此**任何软件都无法把 Fn 当作快捷键**。请在“全局快捷键 → 更改…”中录制你喜欢的组合（需包含 Ctrl / Alt / Shift / Win 之一，F1–F24 可单独使用）。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| 打字速度 WPM | 1 词 = 5 次键击。实际平均速度（含停顿、改错）与设置值一致。汉字按每字约 3 次键击计算。 |
| 节奏随机度 | 每次按键间隔的波动幅度。0% 为机械匀速。 |
| 错字并改正 | 英文字母打错的概率（打成相邻键），之后会退格改正，有时多打一两个字母才发现。 |
| 思考停顿 | 单词之间偶尔停顿较久的概率。 |
| 标点、换行后自然停顿 | 句号、逗号、换行之后稍作停顿。 |
| 换行按键 | 聊天软件里 Enter 会直接发送，可改为 Shift+Enter。 |
| 跳过行首缩进 | 代码编辑器会自动缩进时勾选，避免缩进重复。 |
| 切换窗口时自动暂停 | 打字过程中焦点离开目标窗口会自动暂停，防止打到别处。 |

设置保存在 `%APPDATA%\TypeBot\settings.json`。

## 注意事项

- 如果目标程序以**管理员身份**运行，TypeBot 也必须以管理员身份运行，否则 Windows 会拦截模拟按键。
- 文字通过 Unicode 方式输入，与键盘布局、大小写锁定无关；若遇到中文输入法干扰，切换到英文模式即可。
- 少数游戏或远程桌面软件不接受这种模拟输入。

## 文件结构

- `typebot.py`：界面与控制逻辑
- `engine.py`：节奏模型（生成按键计划）与执行线程
- `winapi.py`：Windows 底层接口（SendInput、RegisterHotKey）
- `tests/`：单元测试，运行 `python -m unittest discover -s tests`
